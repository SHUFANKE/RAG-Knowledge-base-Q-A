# 原始 RAG 论文的记忆与检索

资料类型：根据一手资料编写的中文学习摘要，非官方原文全文。
核验日期：2026-10-04。Python 内容以 3.13 文档为边界；其他资料为当日网页快照摘要。

## 1. 参数与非参数记忆
Lewis 等人的 RAG 原始论文将预训练参数记忆与显式非参数记忆结合，用于语言生成。论文具体模型的参数记忆是预训练 seq2seq 模型，非参数记忆是 Wikipedia 的密集向量索引，由预训练神经检索器访问。

来源：https://arxiv.org/abs/2005.11401v4

## 2. 生成条件的两种形式
原始 RAG 论文比较两种生成条件形式：一种在整个生成序列中使用相同的检索段落；另一种允许不同 token 使用不同检索段落。该描述属于论文模型的两种形式，不能据此断言任何工程 RAG 都实现了逐 token 检索。

来源：https://arxiv.org/abs/2005.11401v4

## 3. 研究动机
原始论文指出，大规模预训练模型虽然把事实存入参数，但精确访问、操纵知识仍有限；为决策提供来源以及更新世界知识也是研究问题。RAG 的检索记忆旨在改善知识密集任务的生成能力，不能由此保证任意部署都不会产生错误。

来源：https://arxiv.org/abs/2005.11401v4
